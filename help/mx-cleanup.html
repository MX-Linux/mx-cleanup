HELP: MX Cleanup

This application offers several easy cleaning actions to help increase/maintain free disk space.


Main tab

Here you will find specific cleaning tools that all are run on a scheduled time.

  • Free disk space for user - select the user that Cleanup is working on with the Select user:↕ control.
  • Clean Folders – cleans Cache and Thumbnails by accessed time or all (potentially dangerous).
  • Delete Logs – delete only old logs or Logs older than: ↕ via chooser.
  • Clear APT Cache - delete only Old files or All files.
  • Clean Flatpak – Remove unused runtimes. Files that were left behind by removed Flatpaks.
  • Empty Trash – Operate on selected user or all users. Setting for Trash older than: ↕

Schedule

The default schedule is No automatic clean. Other choices are: At reboot, Daily, Weekly and Monthly.

Click Apply and then x Close.


Tools tab

Here you will find specialized cleaning tools that are one time actions.

Removal Tools


Remove unused WiFi drivers – Linux kernel 6.14 and later has many RealTek drivers in kernel. This removes the DKM type WiFi drivers that were used by older kernels. This prevents them from being rebuilt needlessly each time a Linux kernel update is applied.


List and select kernels to remove. If you have you kernels auto updating the space consumed then increases over time. This is especially true if kernels are in /boot when root encryption configured.



The Kernel currently in use: kernel can NOT be removed. It is considered a good practice to keep at least 1 kernel beyond the one in use.


Remove MX manuals for languages other than the system default. This frees up disk space taken by manuals and FAQ files (PDF) that are not needed.


Graphical Tool for Analyzing Disk Usage

Clicking Run Disk Usage Analyzer starts an applet that gives a graphical disk usage map display of your used. When first opened it asks you to define a starting point.



Then it shows a Folder list (left). The listing is sorted by the Size of disk space used. Space use is shown as a percentage in the Folder listing and is highlighted as red in the Rings Chart (right).



This allows for a selection of a specific part of the file system to be scanned. A single folder or the entire file system. Clicking a folder updates the display and refreshes the listing of internal details.



Mousing over a given item in the chart (above) shows folder (Host) in light red and component file of it (Windows11_Client_…) in a darker red.


Each directory can be operated on by right clicking and choosing either ‘Open Externally’ (File Manager) or ‘Move to Trash’ options.


Closing caution

Note that there are other cleanup applications available in the repos such as Bleachbit, but these have a significant potential to destroy a Linux OS and should only be used by advanced users.
